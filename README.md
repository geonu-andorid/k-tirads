## 기준 갱신 절차 (유지보수)

이 툴의 판정 수치는 전부 `index.html` 상단 `RULES` 객체에 있습니다. 코드 로직은 수치를 하드코딩하지 않습니다.

1. 근거 고시·공고·가이드라인의 개정 여부를 확인한다 (화면 상단 원문 링크).
2. 바뀐 값이 있으면 `RULES` 의 해당 필드만 수정한다.
3. `RULES.meta.lastVerified` 를 확인한 날짜로 갱신한다 — **개정이 없어도 확인했다면 날짜를 갱신**한다.
4. 커밋·푸시하면 GitHub Pages 에 자동 반영된다.

`lastVerified` 가 1년을 넘기면 화면에 "기준 확인 후 N개월 경과" 경고 배지가 자동으로 뜹니다.
