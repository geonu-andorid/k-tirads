K-TIRADS 갑상선결절 판정

판독 소견을 선택하면 2021 K-TIRADS 표를 조회해 카테고리와 FNA 크기 기준을 표시합니다.

! 이 도구는 영상을 분석하지 않습니다. 사용자가 직접 판독한 소견을 입력받아 학회 권고안의 분류표를 조회할 뿐입니다. 소견 입력값이 결과를 전적으로 결정합니다.

0. 특수 패턴 먼저 확인

아래 패턴에 해당하면 먼저 선택하세요. 선택 시 아래 1~3번 입력보다 우선 적용됩니다. 해당 없으면 그대로 두고 아래 1~4번을 입력하세요.

1. 구성 필수

결절의 내부 구성을 선택하세요.

2. 에코 필수

고형 성분의 에코를 선택하세요.

3. 의심소견 해당 항목만

3종 중 해당하는 항목을 모두 선택하세요. 하나도 없으면 비워 둡니다.

3-1. 추가 소견 선택

부분낭성 결절에서 해당하는 경우에만 선택하세요.

4. 결절 최대직경 FNA 판정에 필요

가장 긴 직경을 입력하세요. (예: 1.4)
